Este proyecto trata de hacer una aplicación que consiste en el juego Mini Tennis. Es una variante del primer juego creado en un ordenador en 1912:

![Imatge Mini Tennis](https://www.pcsteps.com/wp-content/uploads/2017/06/The-First-Computer-Game-Was-Created-in-1912.png)


Utilizamos una raqueta para mantener la pelota en movimiento, con el objetivo de que esta no toque el suelo, ya que si lo hace perderás. Además, hemos añadido variantes para hacer el juego más divertido y aumentar la dificultad a medida que avanzas.
Estas son las implementaciones:

- Añadir niveles y un sistema de puntuación
- Aumentar la velocidad de la pelota por cada nivel añadido
- Obstaculo que se mueve constantemente de forma horizontal
- Música de fondo y sonido al rebotar
- Menú para mejorar la experiencia del usuario
- Base de datos implementada

Para hacer el proyecto hemos utilizado Java, desarrollado con el IDE IntelliJ Community y MySql para la base de datos.
